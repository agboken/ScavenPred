# ScavenPred

ScavenPred is a research tool for antioxidant peptide activity prediction.

## Public web predictor

**Use ScavenPred online:** https://pepsilico.com/tools/scavenpred/

The web interface accepts standard amino-acid sequences, including batch input, and supports downloading prediction results. Its scores are model outputs, not experimentally determined peptide activity.

## Research repository

This is the public ScavenPred research repository referenced in the ScavenPred/ACE-iPred manuscript. The public predictor is served by PepSilico; the web interface and this repository have different purposes.

For methodological reproducibility, use the notebooks, datasets and evaluation materials supplied with the corresponding research release. Web predictions alone do not reproduce cross-validation, feature-selection or model-training results.

## Companion model

ACE-iPred web predictor: https://pepsilico.com/tools/ace-ipred/

## Research under development

SAPIEN-Pep and SIPPAD are separate, research-stage systems. They are not part of the ScavenPred public software release; their engines and proprietary research code are not distributed from this repository.
